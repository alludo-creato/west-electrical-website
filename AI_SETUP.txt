WEST ELECTRICAL WEBSITE: ONLINE AI ASSISTANT SETUP

The standalone HTML preview cannot call the online AI service by itself. The assistant uses server.mjs so the private API key is kept on the server and is never placed in the public webpage.

WHAT IS NEEDED
- A website host that can run Node.js server applications (a static-only host is not enough for this setup).
- Node.js 20 or newer on the host.
- An OpenAI API account with billing/API access. API usage may incur charges.
- Set these private environment variables in the host's settings:
    OPENAI_API_KEY = your secret API key
    OPENAI_MODEL = a model available to your API account
    PORT = supplied by the host, if required by that host

DEPLOY
1. Upload the complete West_Electrical_Website folder to the Node.js host.
2. Set the environment variables in the host dashboard. Do not put your API key in index.html or share it publicly.
3. Set the host's start command to: node server.mjs
4. Open the hosted website and ask the assistant a question. It will answer general questions and company service questions. It is instructed to decline direct insults and abusive attacks politely.

LOCAL PREVIEW
The file West_Electrical_Website.html is only a visual preview. It has the chat design and limited built-in answers; open-ended AI replies require the hosted server and API configuration above.
